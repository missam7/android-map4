# نقشه میدانی — نسخه ۰٫۴

اپ اندروید مستقل (بدون سرور) با Capacitor. رابط داخل `www/` است و کتابخانه‌ها با `esbuild` از `src/` به `www/vendor.js` بسته‌بندی می‌شوند (در `npm install` خودکار).

## تازه در ۰٫۴

- **ظاهر جدید**: نوار مختصات شیشه‌ای، قطب‌نمای ابزاری، دکمه‌های شناور (بزرگ‌نمایی، اطلاعات نقطه، ترافیک، موقعیت من)، نوار پایین شناور، برگه‌های کشویی با دسته و دکمه‌ی بستن، کارت‌های تصویری نقشه‌ی زمینه، آیکون‌های خطی یکدست.
- **تشخیص خودکار مرز اداری روی خود گوشی**: استان (داخل برنامه، از OpenStreetMap)، شهرستان، بخش، منطقه‌ی شهرداری (پس از اولین دریافت از سرور شهرداری برای همیشه ذخیره می‌شود)، ناحیه‌ی ثبتی و پلاک ثبتی (از بسته‌ی مرزی واردشده). نتیجه خودکار در توضیحات هر نقطه‌ی ثبت‌شده، پاپ‌آپ پارسل، دکمه‌ی اطلاعات (ⓘ) و دکمه‌ی گروهی هر لایه نوشته می‌شود.
- **پارسل مشهد** بدون وارد کردن توکن کار می‌کند (توکن پیش‌فرض داخل برنامه).
- **مسیریابی**: نشان (کلید پیش‌فرض داخل برنامه) ← **موتور مسیریابی داخلی** (گراف جاده‌ی OpenStreetMap، الگوریتم A*، مسیرهای جایگزین، کوتاه‌ترین، یک‌طرفه‌ها، میدان‌ها و دستورهای پیچ؛ آفلاین پس از ذخیره‌ی جاده‌ها) ← OSRM ← خط مستقیم.
- **ترافیک گوگل**: برای هر مسیر، وضعیت ترافیک از تایل‌های گوگل خوانده می‌شود؛ نوار رنگی ترافیک، زمان تخمینی اصلاح‌شده، تأخیر و کارت‌های «پیشنهادی / سریع‌ترین / کوتاه‌ترین». موتور داخلی هنگام مسیریابی از ترافیک برای وزن‌دهی یال‌ها استفاده می‌کند.

## ساخت APK روی GitHub

۱. همه‌ی فایل‌های این پروژه را در ریشه‌ی مخزن آپلود کنید (پوشه‌های `www`، `src` و `tools` را بکشید و رها کنید؛ فایل‌های هم‌نام جایگزین می‌شوند).
۲. Actions ← Build APK ← Run workflow؛ `fieldmap-debug-apk` را از Artifacts بگیرید.

> **هشدار امنیتی:** فایل `www/defaults.js` شامل کلید نشان و توکن پارسل مشهد است. مخزن GitHub را حتماً **Private** نگه دارید و APK را فقط به افراد مورد اعتماد بدهید (هر کسی APK را داشته باشد می‌تواند مقادیر را استخراج کند).

## داده‌ی مرز اداری (شهرستان، ناحیه‌ی ثبتی، …)

- **داخل خود برنامه**: تب «نقشه» ← «تشخیص خودکار مرز اداری» ← «فایل مرز را اضافه کنید» (GeoJSON، شیپ‌فایل، KML، DXF).
- **از تایل‌های ذخیره‌شده‌ی سحاک** (پوشه‌ی `SahakMVT` برنامه‌ی دسکتاپ قدیمی):

```bash
npm install
node tools/mvt2pack.mjs SahakMVT/mvtRegUnit --z 10 --out regunit.geojson
node tools/mvt2pack.mjs SahakMVT/mvtProvince --out province.geojson
```

فایل خروجی را در برنامه با همان دکمه‌ی «فایل مرز را اضافه کنید» نصب کنید (یا برای ادغام دائمی داخل APK بدهید).

## محدودیت‌ها

- موتور داخلی: فاصله تا حدود ۹۰ کیلومتر؛ محدودیت‌های گردش (پیچ ممنوع) و ترافیک لحظه‌ای جاده‌های محلی در نظر گرفته نمی‌شود.
- ترافیک گوگل از روی رنگ تایل‌ها تخمین زده می‌شود؛ دقت آن به تغییر ظاهر تایل‌های گوگل وابسته است.
- گزارش‌های عرصه/پروانه/پایان‌کار شهرداری خودکار نیست (کد کپی می‌شود و صفحه‌ی رسمی باز می‌شود).
- DWG پشتیبانی نمی‌شود. ضبط مسیر فقط وقتی صفحه روشن است کار می‌کند.
